ExcedentMarket's domain is expressed through eleven core Eloquent models that span the full circular-economy cycle — from company registration and material cataloguing, through lot publication and negotiation, to payment, physical handover, and regulatory traceability. Each model below is documented with its database table, purpose, key fields, notable constants and scopes, and all declared relationships. Fields marked as **generated** are computed by PostgreSQL and cannot be assigned directly.

---

## LotePublicado

**Table:** `lotes_publicados` — The central trading entity. A `LotePublicado` is a batch of industrial surplus material that a waste-generator company publishes for sale. It drives the entire negotiation lifecycle: from `borrador` through `en_negociacion` to `adjudicado`, reserving warehouse stock along the way.

<Tabs>
  <Tab title="Fillable Fields">
    <ResponseField name="material_id" type="integer" required>
      Foreign key to `materiales`. Must resolve to a Class-C (commercializable) material.
    </ResponseField>
    <ResponseField name="generador_id" type="integer">
      Foreign key to `empresas` (the seller). Nullable for lots not yet assigned to a company.
    </ResponseField>
    <ResponseField name="almacen_id" type="integer">
      Warehouse from which material will be dispatched. Location columns are auto-derived from this at save time.
    </ResponseField>
    <ResponseField name="estado" type="string" required>
      Lifecycle state. One of `borrador`, `publicado`, `en_negociacion`, `adjudicado`, `cerrado`. See [`EstadoLote`](/reference/enums#estadolote).
    </ResponseField>
    <ResponseField name="cantidad" type="decimal(15,2)" required>
      Quantity offered, in the material's `unidad_medida`. Maximum: `MAXIMO_DECIMAL` (9 999 999 999 999.99).
    </ResponseField>
    <ResponseField name="precio_referencia" type="decimal(15,2)">
      Reference unit price in Guaraníes. Maximum: `MAXIMO_DECIMAL`.
    </ResponseField>
    <ResponseField name="modalidad_precio" type="string" required>
      Pricing modality (e.g., `por_unidad`, `precio_total`).
    </ResponseField>
    <ResponseField name="fecha_limite" type="datetime">
      Offer-acceptance deadline. Cast to `datetime`.
    </ResponseField>
    <ResponseField name="clase_residuo" type="string">
      Lot-level waste class declaration (`A`, `B`, or `C`). Evaluated independently of the material's class by `motivoNoPublicable()`.
    </ResponseField>
    <ResponseField name="codigo_residuo_interno" type="string">
      Optional catalog code for this specific lot. Falls back to `material.codigo_interno` via `codigoResiduo()`.
    </ResponseField>
    <ResponseField name="tipo_valorizacion" type="string">
      Circular-economy valorization type. Auto-inherited from the material on creation if not supplied. One of `reutilizacion`, `remanufactura`, `reciclaje`, `recuperacion`.
    </ResponseField>
    <ResponseField name="proceso_valorizacion" type="string">
      Free-text description of the valorization process.
    </ResponseField>
    <ResponseField name="ciudad_id" type="integer">
      FK to `ciudades`. Auto-derived from the warehouse at save time; overridable when the material is collected from a different location.
    </ResponseField>
    <ResponseField name="lat / lng" type="decimal(10,8)">
      Pickup coordinates. Auto-derived from `almacen.lat/lng` unless a custom pickup point is declared.
    </ResponseField>
    <ResponseField name="direccion" type="string">
      Pickup address. Auto-derived from the warehouse; overridable.
    </ResponseField>
    <ResponseField name="registrado_siam_at" type="datetime">
      Date/time the lot was declared to SIAM. The virtual attribute `registrado_siam` returns `true` when this is non-null.
    </ResponseField>
  </Tab>
  <Tab title="Constants & Scopes">

| Constant | Value | Purpose |
|---|---|---|
| `ESTADOS_VISIBLES` | `['publicado', 'en_negociacion']` | Lots shown in the public catalogue and counted on the homepage. |
| `ESTADOS_RESERVAN_STOCK` | `['publicado', 'en_negociacion', 'adjudicado']` | Lots whose `cantidad` is committed in the warehouse (prevents double-publishing). |
| `ESTADOS_CONGELADOS` | `['adjudicado', 'cerrado']` | States after which commercial conditions cannot be modified. |
| `CLASE_PELIGROSA` | `'A'` | Same value as `Material::CLASE_PELIGROSA` — shared regulatory source of truth. |
| `MAXIMO_DECIMAL` | `9999999999999.99` | Derived from `decimal(15,2)` column capacity. |

```php
// Only lots available for bidding (excludes archived)
LotePublicado::visibles()->get();

// Committed quantity for a material in a warehouse
LotePublicado::cantidadComprometida($materialId, $almacenId);

// Reference price range from past published lots (last 6 months)
LotePublicado::rangoPrecioReferencia($materialId);

// Lots with a catalog code (own or from material)
LotePublicado::conCodigoResiduo()->get();
```
  </Tab>
  <Tab title="Relationships">

| Method | Type | Target |
|---|---|---|

| `ciudad()` | `BelongsTo` | `Ciudad` |
| `imagenes()` | `HasMany` | `ImagenLote` — ordered: cover image first, then by `id` |
| `ofertas()` | `HasMany` | `Oferta` (FK: `lote_id`) |
| `contrato()` | `HasMany` | `Contrato` (FK: `lote_id`) |

  <Tab title="Business Methods">

```php

$lote->motivoNoPublicable();

// Why commercial conditions are locked (null = editable)
$lote->motivoBloqueoCondiciones();

```

  </Tab>
</Tabs>

<Note>
  The `sinGuardaDeLicencia()` static method temporarily disables the RF-NEG-01 license check. It exists exclusively for demo seeders and test factories — any other use is a deliberate bypass of the publishing rule and is visible via `grep`.
</Note>

## Empresa

**Table:** `empresas` — Represents a registered business entity, either a waste generator (`generador`), recycler (`reciclador`), or both (`ambos`). Stores RUC (tax ID), environmental license status, encrypted contact data, and warehouse/lot relationships.

<Tabs>
  <Tab title="Fillable Fields">
    <ResponseField name="nombre" type="string" required>
      Legal company name.
    </ResponseField>
    <ResponseField name="ruc" type="string" required>
      Paraguay tax ID (RUC). Stored in plaintext — used as the DNIT registry cross-reference key.
    </ResponseField>
    <ResponseField name="tipo" type="string" required>
      Role in the marketplace: `generador`, `reciclador`, or `ambos`.
    </ResponseField>
    <ResponseField name="estado" type="string">
      Company account status.
    </ResponseField>
    <ResponseField name="logo_url" type="string">
      Relative path within the `public` disk, or an absolute URL for static assets.
    </ResponseField>
    <ResponseField name="telefono" type="string (encrypted)">
      Contact telephone. Encrypted at rest under Ley N.° 7.593/2025.
    </ResponseField>
    <ResponseField name="direccion" type="string (encrypted)">
      Physical address. Encrypted at rest. `ciudad_id` is stored unencrypted to support geographic marketplace filters.
    </ResponseField>
    <ResponseField name="ciudad_id" type="integer">
      FK to `ciudades`. Left unencrypted to enable geographic filtering.
    </ResponseField>
  </Tab>
  <Tab title="Constants & Scopes">

```php
// RUC/DNIT validation state labels (8 keys)
Empresa::ESTADOS_RUC_DNIT;
// Keys: 'valido_activo', 'valido_suspension_temporal', 'valido_cancelado',
//       'no_encontrado', 'formato_invalido', 'padron_vacio',
//       'padron_desactualizado', 'pendiente'

// Companies that can publish lots (generador + ambos)
Empresa::TIPOS_QUE_VENDEN; // ['generador', 'ambos']

// Companies that can bid on lots (reciclador + ambos)
Empresa::TIPOS_QUE_COMPRAN; // ['reciclador', 'ambos']

// Scope: generator companies
Empresa::vendedoras()->get();

// Scope: recycler companies
Empresa::compradoras()->get();

// Scope: filter by DNIT validation state
Empresa::conEstadoRuc('valido_activo', 'pendiente')->get();
```

  </Tab>
  <Tab title="Relationships">

| Method | Type | Target |
|---|---|---|
| `users()` | `HasMany` | `User` |
| `destinatarios()` | `HasMany` | `User` — excludes users who exercised deletion rights (Ley N.° 7.593 Art. 31) |
| `almacenes()` | `HasMany` | `Almacen` |
| `lotesPublicados()` | `HasMany` | `LotePublicado` (FK: `generador_id`) |
| `licencias()` | `HasMany` | `LicenciaEmpresa` |
| `ultimaValidacionRuc()` | `HasOne` | `RucValidacion` (latest) |
| `contratosComoGenerador()` | `HasManyThrough` | `Contrato` via `LotePublicado` |
| `ofertasComoReciclador()` | `HasMany` | `Oferta` (FK: `reciclador_id`) |
| `contratosComoReciclador()` | `HasMany` | `Contrato` (FK: `reciclador_id`) |
| `categoriasInteres()` | `BelongsToMany` | `CategoriaMaterial` via `empresa_categoria_interes` |
| `valorizacionesInteres()` | `HasMany` | `ValorizacionInteres` |

  </Tab>
  <Tab title="Publishing Rules">

```php
// Can this company publish lots? (Ley N.° 294/93 Art. 7)
$empresa->puedePublicarLotes();          // bool
$empresa->motivoBloqueoPublicacion();    // ?string

// Can this company bid on lots? (RF-NEG-12, Ley N.° 3956/09 Art. 26)
$empresa->puedeOfertar();               // bool
$empresa->motivoBloqueoOferta();        // ?string

// Latest approved environmental license
$empresa->licenciaAmbiental();          // ?LicenciaEmpresa

// Logo URL or SVG initials avatar
$empresa->logoUrl();                    // ?string
$empresa->logoOAvatar();               // string
```

  </Tab>
</Tabs>

<Warning>
  The `tipo` field uses three values — `generador`, `reciclador`, `ambos` — but **`ambos` is not a third role**; it is the union of the other two. Never filter with `where('tipo', 'generador')` alone: always use `whereIn('tipo', Empresa::TIPOS_QUE_VENDEN)` or the `scopeVendedoras()` / `scopeCompradoras()` scopes.
</Warning>

## User

**Table:** `users` — Authenticatable system user. Always belongs to an `Empresa`. Roles are managed by Spatie `HasRoles`. TOTP secret and recovery codes are encrypted. Contact fields (`telefono`, `cargo`) are encrypted under Ley N.° 7.593/2025.

<Tabs>
  <Tab title="Fields">
    <ResponseField name="name" type="string" required>
      Display name. Stored in plaintext (used in the search index).
    </ResponseField>
    <ResponseField name="email" type="string" required>
      Login email. Stored in plaintext — used as the TOTP issuer identifier.
    </ResponseField>
    <ResponseField name="password" type="string (hashed)" required>
      Bcrypt/Argon hash.
    </ResponseField>
    <ResponseField name="empresa_id" type="integer">
      FK to `empresas`. Every operational user belongs to one company.
    </ResponseField>
    <ResponseField name="telefono" type="string (encrypted)">
      Personal phone. Encrypted at rest.
    </ResponseField>
    <ResponseField name="cargo" type="string (encrypted)">
      Job title/position. Encrypted at rest.
    </ResponseField>
    <ResponseField name="privacy_accepted_at" type="datetime">
      Timestamp of privacy policy acceptance.
    </ResponseField>
    <ResponseField name="privacy_policy_version" type="string">
      FK-style reference to `politicas_privacidad` — tracks which version was accepted.
    </ResponseField>
    <ResponseField name="deletion_requested_at" type="datetime">
      Set when the user exercises the right to erasure (Ley N.° 7.593 Art. 31). The row is anonymised but retained as evidence of compliance.
    </ResponseField>
    <ResponseField name="app_authentication_secret" type="string (encrypted)">
      TOTP secret. Encrypted — equivalent in sensitivity to the password.
    </ResponseField>
    <ResponseField name="app_authentication_recovery_codes" type="encrypted:array">
      TOTP recovery codes. Encrypted array.
    </ResponseField>
  </Tab>
  <Tab title="Panel Access">

```php
// Panel access is role-gated (explicit allowlist, not dynamic)
public function canAccessPanel(Panel $panel): bool
{
    return match ($panel->getId()) {
        'admin'     => $this->hasRole('admin'),
        'generador' => $this->hasRole('generador'),
        'reciclador'=> $this->hasRole('reciclador'),
        default     => false,
    };
}
```

  </Tab>

| Spatie roles | via `HasRoles` | `roles`, `permissions` |

## Contrato

**Table:** `contratos` — Created when an offer is accepted by a generator. Freezes the agreed unit price, quantity, and applicable commission rate at creation time. `monto_material` and `comision_plataforma` are **PostgreSQL-generated columns** and cannot be written by Eloquent.

<Tabs>
  <Tab title="Fillable Fields">
    <ResponseField name="lote_id" type="integer" required>
      FK to `lotes_publicados`.
    </ResponseField>
    <ResponseField name="oferta_id" type="integer" required>
      FK to `ofertas` — the winning offer that originated this contract.
    </ResponseField>
    <ResponseField name="reciclador_id" type="integer" required>
      FK to `empresas` (the buyer).
    </ResponseField>
    <ResponseField name="precio_unitario" type="decimal(15,0)" required>
      Frozen unit price in Guaraníes.
    </ResponseField>
    <ResponseField name="cantidad" type="decimal(15,2)" required>
      Quantity contracted.
    </ResponseField>
    <ResponseField name="tasa_comision_aplicada" type="decimal(6,4)" required>
      Commission rate frozen at creation. Default: `TASA_COMISION` (0.03 = 3%).
    </ResponseField>
    <ResponseField name="estado" type="string" required>
      See [`EstadoContrato`](/reference/enums#estadocontrato): `pendiente_pago`, `activo`, `completado`, `cancelado`, `incumplido`.
    </ResponseField>
    <ResponseField name="pasarela" type="string">
      Payment gateway used: `pagopar` or `dlocalgo`.
    </ResponseField>
  </Tab>
  <Tab title="Generated Columns">
    <ResponseField name="monto_material" type="decimal(15,0) — GENERATED">
      `precio_unitario × cantidad`, rounded to Guaraní. Computed by PostgreSQL. Read-only via Eloquent.
    </ResponseField>
    <ResponseField name="comision_plataforma" type="decimal(15,0) — GENERATED">
      `monto_material × tasa_comision_aplicada`. Computed by PostgreSQL. Read-only via Eloquent.
    </ResponseField>
  </Tab>
  <Tab title="Constants">

```php
// Platform commission rate (frozen at contract creation)
Contrato::TASA_COMISION; // 0.03

// Always read the applied rate from the contract — never the constant
$contrato->tasaComisionAplicada(); // float
```

  </Tab>
  <Tab title="Relationships">

| Method | Type | Target |
|---|---|---|
| `lote()` | `BelongsTo` | `LotePublicado` |
| `oferta()` | `BelongsTo` | `Oferta` |
| `reciclador()` | `BelongsTo` | `Empresa` (FK: `reciclador_id`) |
| `pagos()` | `HasMany` | `Pago` |
| `constancia()` | `HasOne` | `ConstanciaTransmision` |
| `documentos()` | `HasMany` | `DocumentoCertificacion` |
| `movimientosStock()` | `HasMany` | `MovimientoStock` |

  </Tab>
</Tabs>

<Info>
  `fecha_adjudicacion` is a virtual attribute that returns `created_at` — adjudication and contract creation happen in the same database transaction via `OfertaService::aceptarOferta()`.
</Info>

## Oferta

**Table:** `ofertas` — A price proposal submitted by a recycler company on a published lot. Supports a single round of counter-offering by the generator. Three columns (`monto_ofertado`, `monto_contraoferta`, `precio_unitario_vigente`) are **PostgreSQL-generated** and cannot be written by Eloquent.

<Tabs>
  <Tab title="Fillable Fields">
    <ResponseField name="lote_id" type="integer" required>
      FK to `lotes_publicados` (explicit key — not auto-derived from model name).
    </ResponseField>
    <ResponseField name="reciclador_id" type="integer" required>
      FK to `empresas` (the bidding company).
    </ResponseField>
    <ResponseField name="precio_unitario_ofertado" type="decimal(15,0)" required>
      Initial bid price per unit, in Guaraníes.
    </ResponseField>
    <ResponseField name="cantidad" type="decimal(15,2)" required>
      Quantity bid for.
    </ResponseField>
    <ResponseField name="precio_unitario_contraoferta" type="decimal(15,0)">
      Counter-offer unit price proposed by the generator (single round only).
    </ResponseField>
    <ResponseField name="contraoferta_at" type="datetime">
      When the counter-offer was submitted.
    </ResponseField>
    <ResponseField name="canal" type="CanalOferta" required>
      Origin of the offer: `marketplace` (React public UI) or `panel` (Filament Reciclador panel). No database default — each entry point must declare it.
    </ResponseField>
    <ResponseField name="estado" type="string" required>
      See [`EstadoOferta`](/reference/enums#estadooferta).
    </ResponseField>
  </Tab>
  <Tab title="Constants & Scopes">

```php
// States in which the negotiation is still open for the buyer
Oferta::ESTADOS_ACTIVOS;        // ['pendiente', 'contrarrestada', 'aceptada']

// States in which the lot is still "in negotiation"
Oferta::ESTADOS_EN_NEGOCIACION; // ['pendiente', 'contrarrestada']

// Active offers
Oferta::activas()->get();

// Active offers by a company on a specific lot
Oferta::deEmpresaEnLote($empresaId, $loteId)->activas()->get();
```

  </Tab>
  <Tab title="Business Methods">

```php
// Current unit price (counter-offer if present, otherwise original bid)
$oferta->precioUnitarioVigente();  // float

// Amount that would become the contract value
$oferta->montoVigente();           // float

// Is the ball in the buyer's court?
$oferta->esperaRespuestaDelComprador(); // bool

// Can the bidder withdraw? (only 'pendiente' offers)
$oferta->puedeRetirarse();         // bool

// The contract born from this offer (null if lost to a competitor)
$oferta->contratoPropio();         // ?Contrato
```

  </Tab>
  <Tab title="Relationships">

| Method | Type | Target |
|---|---|---|
| `lote()` | `BelongsTo` | `LotePublicado` |
| `reciclador()` | `BelongsTo` | `Empresa` |
| `contratoDelLote()` | `HasOne` | `Contrato` — the lot's contract (may belong to a competitor) |

  </Tab>
</Tabs>

## Material

**Table:** `materiales` — Catalogue entry for a waste or surplus material type. Only **active Class-C materials** are commercializable. Provides the suggested valorization type and CO2 emission factor used in the lot's circular score.

<Tabs>
  <Tab title="Fillable Fields">
    <ResponseField name="nombre" type="string" required>
      Material name (e.g., "Polietileno de alta densidad").
    </ResponseField>
    <ResponseField name="categoria_id" type="integer" required>
      FK to `categorias_material`.
    </ResponseField>
    <ResponseField name="unidad_medida" type="string" required>
      See [`UnidadMedida`](/reference/enums#unidadmedida): `kg`, `ton`, `litros`, `unidades`, `m3`.
    </ResponseField>
    <ResponseField name="activo" type="boolean" required>
      Whether the material is available in the catalogue.
    </ResponseField>
    <ResponseField name="clase_residuo" type="string" required>
      Waste class per Decreto N.° 7.391/17: `A`, `B`, or `C`. See [`ClaseResiduo`](/reference/enums#claseresiduo).
    </ResponseField>
    <ResponseField name="codigo_interno" type="string">
      Internal catalogue code. Used as fallback when a lot has no `codigo_residuo_interno`.
    </ResponseField>
    <ResponseField name="codigo_ler" type="string">
      European Waste Catalogue (LER/EWC) code for cross-reference.
    </ResponseField>
    <ResponseField name="tipo_valorizacion_sugerido" type="string">
      Suggested [`TipoValorizacion`](/reference/enums#tipovalorizacion) — auto-inherited by new lots when `tipo_valorizacion` is not set.
    </ResponseField>
    <ResponseField name="proceso_valorizacion_sugerido" type="string">
      Free-text description of the suggested valorization process. Also auto-inherited by new lots.
    </ResponseField>
    <ResponseField name="precio_referencia_min / precio_referencia_max" type="integer">
      Market price range in Guaraníes per unit. Used by seeders and `precioVerosimil()`.
    </ResponseField>
  </Tab>
  <Tab title="Constants & Scopes">

```php
// Shared source of truth for Class A value
Material::CLASE_PELIGROSA; // 'A'

// Positive-criterion scope: active AND clase_residuo = 'C' ONLY
// An unclassified material does NOT enter the catalogue by default
Material::comercializable()->get();
```

  </Tab>
  <Tab title="Relationships">

| Method | Type | Target |
|---|---|---|
| `categoria()` | `BelongsTo` | `CategoriaMaterial` |
| `factoresEmision()` | `HasMany` | `FactorEmision` — ordered by `id DESC` (most recent first) |
| `stocks()` | `HasMany` | `Stock` |
| `lotesPublicados()` | `HasMany` | `LotePublicado` |
| `movimientosStock()` | `HasMany` | `MovimientoStock` |

  </Tab>
</Tabs>

<Warning>
  `scopeComercializable()` is a **positive-criterion rule**: it explicitly requires `clase_residuo = 'C'`. An unclassified material is not sold until someone classifies it. Do not use `!= 'A'` logic — it silently commercializes everything that was never reviewed.
</Warning>

## Almacen

**Table:** `almacenes` — Physical warehouse belonging to an `Empresa`. Tracks geographic coordinates that propagate automatically to all lots that inherit their location from it. Uses the `Archivable` concern.

<ResponseField name="empresa_id" type="integer" required>
  Owner company FK.
</ResponseField>
<ResponseField name="nombre" type="string" required>
  Warehouse name.
</ResponseField>
<ResponseField name="direccion" type="string">
  Street address.
</ResponseField>
<ResponseField name="ciudad_id" type="integer">
  FK to `ciudades`.
</ResponseField>
<ResponseField name="lat / lng" type="decimal(10,8)">
  Coordinates used by the marketplace Haversine proximity search.
</ResponseField>

**Relationships:** `empresa()` → `Empresa`, `ciudad()` → `Ciudad`, `stocks()` → `Stock`, `movimientos()` → `MovimientoStock`, `lotesPublicados()` → `LotePublicado`.

<Info>

## MovimientoStock

## LicenciaEmpresa

**Table:** `licencias_empresa` — Environmental license filed by a company with MADES (Paraguay's environmental ministry). Governs whether the company can publish lots or submit offers. Validity is **derived** from `fecha_firma + intervalo_auditoria_meses`, not stored as a separate date.

    <ResponseField name="archivo_pdf" type="string">Relative storage path for the uploaded PDF.</ResponseField>

    <ResponseField name="lote_id" type="integer" required>FK to `lotes_publicados`.</ResponseField>
    <ResponseField name="numero_constancia" type="string" required>
      Sequential unique certificate number. Format: `CT-YEAR-NNNNN`.
